# คู่มือใช้งานสำหรับทีมตรวจทรัพย์สิน

เปิดเว็บด้วยมือถือหรือแท็บเล็ต ไม่ต้องติดตั้งแอป — แนะนำให้ "เพิ่มไปยังหน้าจอโฮม" จะเปิดง่ายเหมือนแอปทั่วไป

---

## เริ่มต้นครั้งแรก

1. เปิดลิงก์ที่หัวหน้าทีมส่งให้ → กด **สมัครสมาชิก** → กรอกอีเมลและรหัสผ่าน (อย่างน้อย 6 ตัว)
2. รอหัวหน้าทีมอนุมัติ (หน้าจอจะพาเข้าระบบเองอัตโนมัติ ไม่ต้องกดรีเฟรช)
3. ครั้งต่อไปเครื่องจะจำการเข้าระบบไว้ ไม่ต้อง login ใหม่ทุกวัน

**ชื่อผู้ตรวจ** จะถูกบันทึกอัตโนมัติจากบัญชีของคุณในทุกครั้งที่บันทึก ไม่ต้องกรอกเอง

---

## หน้าจอหลัก

แถบล่างสุดมี 4–5 ปุ่ม:

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| 🏠 หน้าหลัก | เลือก **รอบการตรวจนับ** ที่จะทำงาน |
| ▤ รายการ | ทะเบียนทรัพย์สินของรอบที่เปิดอยู่ |
| ▣ ปุ่มกลางจอ | **สแกน QR** |
| 📊 สรุปผล | ความคืบหน้าของรอบ + ดาวน์โหลด Excel |
| ⚙ จัดการ | เฉพาะหัวหน้าทีม (อนุมัติบัญชี) |

### รอบการตรวจนับ (หน้าหลัก)

งานตรวจแบ่งเป็น "รอบ" เหมือนระบบ MCR — **1 รอบ = ไฟล์ทะเบียนทรัพย์สิน 1 ไฟล์ที่อัปโหลด**
แต่ละการ์ดบอก: ชื่อโครงการ · ชื่อรอบ · วันที่ตรวจ · จำนวนทรัพย์สิน · ความคืบหน้า · สถานะ

- กด **เปิดตรวจนับ** เพื่อเริ่มทำงานในรอบนั้น (ชื่อโครงการจะขึ้นบนหัวจอตลอดเวลา)
- กด **Dashboard** เพื่อดูสรุปผลของรอบ
- กด 🗑 เพื่อลบรอบ (ลบทะเบียน + ผลตรวจของรอบนั้นทั้งหมด — กู้คืนไม่ได้)
- **＋ สร้างรอบตรวจ** = อัปโหลดไฟล์ทะเบียนของรอบใหม่

ค้นหา/กรองสถานะ/เรียงลำดับรอบได้จากแถบด้านบน

### ไฟล์ทะเบียนที่อัปโหลดได้

ใช้ได้ทั้งไฟล์ทะเบียนต้นฉบับจาก SAP และ **ไฟล์ Excel ที่ export ออกจากระบบนี้เอง** (เอารอบเก่ามาตั้งต้นรอบใหม่)

ระบบอ่านเฉพาะชีทที่เป็น**ทะเบียนจริง** — ต้องมีคอลัมน์ `Inventory Number` คู่กับ `Asset Number`
(ชีท Fixed Assets) หรือ `Material` (ชีทของเช่า) · ชีทอื่นในไฟล์ export เช่น **สรุปผล** และ
**ประวัติการตรวจทั้งหมด** จะถูกข้ามอัตโนมัติ

หลังเลือกไฟล์ กล่องสรุปจะบอกชัดว่า**อ่านมาจากชีทไหน กี่รายการ และข้ามชีทไหนไปบ้าง**
ถ้าจำนวน "ของเช่า" เป็น 0 จะขึ้นเตือนสีส้มให้ตรวจไฟล์ก่อนสร้างรอบ

### ในรอบตรวจ

ทรัพย์สินแยก 2 ประเภทด้วยปุ่มสลับด้านบน: **🏢 Fixed Assets** และ **🚚 ของเช่า**
แต่ละประเภทมีตัวนับ "ตรวจแล้ว x / y" ของตัวเอง (ถ้าสแกนเจอของอีกประเภท ระบบเปิดให้บันทึกได้เลย
ไม่ต้องสลับก่อน)

**สีขอบซ้ายของแต่ละแถว** บอกสถานะทันที: เขียว = พบปกติ · เหลือง = ชำรุด · แดง = ไม่พบ ·
น้ำเงิน = ย้ายออก · เทา = ยังไม่ตรวจ

### 2 มุมมอง: ตาราง / การ์ด

- **▤ ตาราง** (ค่าเริ่มต้น) — เห็นหลายรายการพร้อมกัน **ติ๊กและบันทึกได้ในหน้าเดียว**
- **▦ การ์ด** — แถวใหญ่ อ่านง่าย เหมาะกับการไล่ดูทีละรายการ

สลับได้ตลอดเวลา ระบบจำมุมมองล่าสุดไว้ให้

**ทะเบียนหลักพันรายการจะทยอยแสดง** ครั้งละ 150 รายการ แล้วต่อให้เองเมื่อเลื่อนถึงท้ายรายการ
(หรือกดปุ่ม **แสดงเพิ่ม**) — ตัวเลข "ตรวจแล้ว x / y" ยังนับจาก**ทั้งหมดที่กรองอยู่** ไม่ใช่เฉพาะที่เห็นบนจอ
และปุ่มติ๊ก "เลือกทั้งหมด" ก็ยังเลือกครบทุกรายการที่กรองไว้เช่นเดิม

> รอบใหญ่อย่าง KL-12 (2,487 รายการ) เดิมวาดทั้งตารางทีเดียวจนมือถือหน่วง — ตั้งแต่ v2.8.1
> เหลือวาดเท่าที่เห็นจริง เร็วขึ้นราว 10 เท่า และการค้นหา/กรองยังค้นจากทั้งทะเบียนเหมือนเดิม

## วิธีที่ 1: ตรวจด้วยการสแกน QR (เร็วที่สุด)

1. กดปุ่มส้มกลางจอ → อนุญาตให้ใช้กล้อง (ถามครั้งแรกครั้งเดียว)
2. เล็ง QR ที่ติดบนทรัพย์สินให้อยู่ในกรอบส้ม
3. เครื่องจะ**ร้องปี๊บ + สั่น** แล้วเด้งข้อมูลทรัพย์สินขึ้นมาให้ตรวจสอบ
4. เลือกผลการตรวจ → กด **บันทึกผลตรวจ**
5. กล้องกลับมาพร้อมสแกนตัวถัดไปทันที

ถ้าสแกนแล้ว**ไม่พบรหัสในทะเบียน** ระบบจะแจ้งพร้อมให้เลือก "สแกนต่อ" หรือ
"บันทึกนอกทะเบียน" (สำหรับของที่มีอยู่จริงหน้างานแต่ไม่มีในไฟล์ทะเบียน)

### QR ของบริษัทเก็บ "Asset Number" ไม่ใช่ RT code — ระบบจับคู่ให้เอง

สติกเกอร์ที่ติดของจริง (เช่น `Asset: 301013807` / `RT-DESK-26-0007`) ตัว QR เก็บ**เลข Asset Number**
ระบบจึงค้นให้ครบทุกช่องในทะเบียนรอบนั้น: **RT code → Asset Number → Material → Serial**
(ตัดขีด/ตัดศูนย์นำหน้าให้เอง และถ้า QR เป็นข้อความยาวหรือ URL ก็จะแยกเลขข้างในมาค้นให้)

- เจอ 1 รายการ → เปิดหน้าบันทึกทันที และขึ้นข้อความบอกว่า "QR อ่านได้ … → ตรงกับ RT-…"
- เลขนั้นตรงหลายรายการ (เช่น Asset Number เดียวกันหลาย Sub) → ให้เลือกก่อนบันทึก
- ไม่ตรงอะไรเลย → แจ้ง **ค่าที่อ่านได้จาก QR** ตรงๆ เพื่อให้เทียบกับทะเบียนได้ทันที
  แล้วเลือก "สแกนต่อ" หรือ "บันทึกนอกทะเบียน"

ตรวจการจับคู่ล่วงหน้าได้: พิมพ์เลข Asset Number ลงช่องค้นหาในหน้ารายการ ถ้าเจอแถวแปลว่าสแกนแล้วจะเจอแน่นอน

### สแกนอย่างไรให้ติดไว

- ถือห่าง **20–30 ซม.** ใกล้เกินไปกล้องมือถือโฟกัสไม่เข้า ภาพเบลอจะอ่านไม่ออก
- ไม่ต้องเล็งให้ตรงกรอบเป๊ะ — ระบบไล่อ่าน**ทั้งภาพ**และ**ซูมเข้ากลางจอ**สลับกันตลอดเวลา
  QR ที่อยู่ริมจอหรือ QR เล็กๆ ไกลๆ ก็จับได้ · เอียงได้ถึงประมาณ 45°
- แสงน้อยกดปุ่ม **ไฟฉาย** มุมขวาบน (Android ใช้ได้ · iPhone ระบบไม่เปิดไฟฉายจากเว็บ ให้เปิดไฟรอบข้างแทน)
- สติกเกอร์เคลือบมันสะท้อนแสง ให้เอียงหลบแสงเล็กน้อย (ระบบมีรอบดันคอนทราสต์ช่วยอยู่แล้วส่วนหนึ่ง)

### อ่านไม่ออกจริงๆ ให้ใช้ "ถ่ายรูปให้ระบบอ่าน"

ปุ่มขาวล่างจอ — ใช้**กล้องของเครื่องถ่ายรูป** (โฟกัสและปรับแสงเก่งกว่าภาพสดในเบราว์เซอร์มาก)
แล้วระบบอ่าน QR จากรูปความละเอียดเต็มให้ทันที · เลือกรูปที่ถ่ายไว้แล้วในเครื่องก็ได้
วิธีนี้ได้ผลแม้ QR เล็กมากหรืออยู่มุมภาพ และใช้ได้แม้ตอนกล้องสดเปิดไม่ขึ้น

## วิธีที่ 2: ติ๊ก Yes / No ในตาราง (เหมือนกรอกฟอร์มกระดาษ)

มุมมอง **▤ ตาราง** จัดคอลัมน์ให้ตรงกับฟอร์มรายงานตรวจสอบทรัพย์สินที่ทีมใช้อยู่ทุกประการ —
NO. · Asset Class · Asset Number · Sub Numb · Inventory Number · Description · Serial Number ·
Staff – Text · Current Site · **ผลการตรวจเช็ค (Yes / No)** · ย้ายออก (ส่งไป SITE / เลขที่ใบส่ง /
วันที่ส่ง) · หมายเหตุ

| ช่อง | ผล |
|---|---|
| ติ๊ก **Yes** | บันทึกทันทีว่า **พบ** |
| ติ๊ก **No** | บันทึกทันทีว่า **ไม่พบ** |
| ปุ่ม **⋯** | เปิดหน้ารายละเอียด (ย้ายออก แนบรูป ใส่หมายเหตุ ดูประวัติ) |

ช่อง Yes/No ปักติดขอบขวาเสมอ กดได้ทันทีแม้บนมือถือ · คอลัมน์อื่นจะซ่อนอัตโนมัติเมื่อจอแคบ
(เลื่อนตารางไปทางขวาเพื่อดูคอลัมน์ที่เหลือ หรือหมุนจอเป็นแนวนอน)

**ติ๊กหลายรายการพร้อมกัน:** ติ๊ก ☐ หน้าแถว (หรือติ๊กช่องบนหัวตารางเพื่อเลือกทั้งหมดที่กรองอยู่)
→ แถบด้านล่างขึ้นว่าเลือกกี่รายการ → ใส่ตำแหน่ง (ถ้าต้องการ) → กด **✅ พบ** หรือ **❌ ไม่พบ**
ระบบบันทึกให้ทุกรายการที่เลือกในครั้งเดียว

**ลบประวัติหลายรายการ (เฉพาะผู้ดูแล):** เลือกรายการแล้วกด **🗑 ลบประวัติ** ในแถบเดียวกัน
รายการที่เลือกจะกลับเป็น "ยังไม่ตรวจ" ใช้ตอนตรวจผิดรอบหรือต้องการเริ่มนับใหม่

แตะที่แถว (นอกช่องติ๊ก) = เปิดรายละเอียดของรายการนั้น

## วิธีที่ 3: ค้นหาแล้วเลือกทีละรายการ

1. ค้นหาด้วยช่องบนสุด (พิมพ์ได้ทั้งรหัส ชื่อ Serial ชื่อผู้รับผิดชอบ — พิมพ์หลายคำได้ ระบบหาที่ตรงครบทุกคำ)
2. แตะแถวที่ต้องการ → เลือกผลการตรวจ → บันทึก

## วิธีที่ 4: โหมดตรวจต่อเนื่อง (ของหมวดเดียวกันจำนวนมาก)

เหมาะกับตรวจของชนิดเดียวกันเรียงกันเยอะๆ เช่น ตู้โหลด `RT-MDBX` หลายสิบตัว

1. กดปุ่ม **⚡ โหมดตรวจต่อเนื่อง**
2. เลือกหมวด เช่น `RT-MDBX` → ระบบจะ**ค้าง prefix ไว้ให้**
   - **เลือกได้หลายหมวดพร้อมกัน** (เช่น RT-APRX + RT-BENX) โดยติ๊กในรายการหมวด
     พิมพ์ค้นหาหมวดได้ · หมวดที่เลือกจะขึ้นเป็นป้ายให้เห็นและตัวนับรวมทุกหมวดที่เลือก
   - เวลาเลือกหลายหมวด ระบบจะหาให้เองว่าเลขที่พิมพ์ตรงกับหมวดไหน — ถ้าเลขนั้นมีอยู่ในหมวดเดียว
     บันทึกทันที ถ้ามีซ้ำในหลายหมวดจะถามให้เลือกก่อน จึงไม่ต้องสลับหน้าจอไปมา
   - ใต้ช่องกรอกมีบรรทัดบอกล่วงหน้าตลอดว่า**เลขที่พิมพ์อยู่จะลงหมวดไหน** (เขียว = ลงหมวดนี้แน่นอน,
     ส้ม = ตรงกันหลายหมวดเดี๋ยวจะให้เลือก, แดง = ไม่มีเลขนี้ในหมวดที่เลือก)
3. **พิมพ์เฉพาะตัวเลขส่วนท้าย ไม่ต้องพิมพ์ขีด** ระบบใส่ให้เอง — พิมพ์ `262222` จะกลายเป็น `26-2222`
   - บนมือถือ/แท็บเล็ตจะขึ้น **แป้นตัวเลขล้วนแบบกดเบอร์โทร** พิมพ์ได้ไวและไม่กดโดนตัวอักษร
   - พิมพ์สั้นก็ได้ เช่น `07766` → ระบบเติมเป็น `07-0766`
4. **บันทึกเองเมื่อครบ 6 หลัก** (เปิดไว้ให้อยู่แล้ว) — พอพิมพ์ครบระบบบันทึกทันทีไม่ต้องกดปุ่ม
   ถ้าอยากกดยืนยันเองทุกครั้ง ให้ติ๊กออกที่ช่อง "บันทึกเองเมื่อครบ 6 หลัก"
5. รหัสที่ปีเป็นตัวอักษร **YY** (เช่น `RT-MDBX-YY-0163`) กดปุ่ม **ใส่ปี YY** แล้วพิมพ์ 4 ตัวท้ายต่อ
6. ช่องกรอกเคลียร์ให้เองพร้อมรับตัวถัดไป **prefix ยังอยู่** เคอร์เซอร์กลับมาที่ช่องเดิมอัตโนมัติ
7. มีตัวนับสะสม "ตรวจแล้ว x / y รายการในหมวดนี้" ให้เห็นตลอด

ถ้ากรอกรหัสที่มีคนตรวจไปแล้ว ระบบจะ**เตือนทันทีว่าใครตรวจ เมื่อไหร่ ผลเป็นอะไร** แล้วให้เลือกว่าจะบันทึกซ้ำหรือไม่

### เลขท้ายซ้ำกันคนละหมวด — ระบบไม่เดาให้

เช่นเลือกทั้ง `RT-ABCD` และ `RT-DCBA` แล้วพิมพ์ `26-0001` ซึ่งมีอยู่จริงทั้งสองหมวด
ระบบ **จะไม่เลือกให้เองไม่ว่ากรณีใด** แต่จะเปิดหน้าต่างให้เลือกก่อนบันทึกเสมอ:

- รายการเรียงตามชื่อหมวด (A→Z) ลำดับปุ่มจึงไม่สลับไปมา
- แต่ละปุ่มมี**เลขกำกับ 1, 2, 3** — บนคอมกดเลขบนคีย์บอร์ดได้เลย บนมือถือแตะปุ่ม · กด **Esc** = ยกเลิก
- แต่ละปุ่มบอกคำอธิบายของและสถานะปัจจุบัน (ยังไม่ตรวจ / พบ / ไม่พบ / กี่ชิ้น) จะได้เลือกไม่ผิดตัว
- เลือกแล้วบรรทัด "ล่าสุด" จะแสดง**รหัสเต็มที่บันทึกจริง** ไว้ตรวจซ้ำได้ทันที

ถ้าเลขนั้นมีอยู่จริงแค่หมวดเดียวในบรรดาหมวดที่เลือกไว้ ระบบบันทึกหมวดนั้นทันทีโดยไม่ถาม
(ไม่มีทางลงผิดหมวด เพราะอีกหมวดไม่มีเลขนี้อยู่ในทะเบียนรอบนั้น)

---

## วิธีที่ 5: นับจำนวน (เจอของแต่ไม่ทราบ RT code)

เหมาะกับของกองรวมกันหรือสติกเกอร์หลุด เช่น เก้าอี้ 20 ตัวที่ไม่รู้รหัสรายตัว

1. ในหน้ารายการกด **# นับจำนวน**
2. เลือก **หมวดทรัพย์สิน** (เช่น RT-CHXX) → กรอก **จำนวนที่นับได้** (มีปุ่ม +1 / +5 / +10 ให้กดเร็ว)
3. ใส่ **จุดที่นับ** เช่น "ชั้น 3 โซน B" แล้วกด **บันทึกยอดนับ**
4. ระบบเทียบยอดให้ทันที: **ทะเบียนหมวดนี้ / นับเจอสะสม / ยังไม่เจอ**

- นับหลายจุดได้เรื่อยๆ ระบบ**รวมยอดสะสม**ให้เอง (แต่ละครั้งเก็บเวลา จุดที่นับ และผู้นับไว้ครบ)
- ยอดนับ **แยกจากผลตรวจรายชิ้นโดยสิ้นเชิง** ไม่ไปติ๊กพบ/ไม่พบให้รหัสใดๆ ข้อมูลรายชิ้นจึงไม่เพี้ยน
- **หมวดที่ไม่มีในทะเบียนก็นับได้** — เลือก **"+ หมวดอื่น (พิมพ์เอง)"** แล้วพิมพ์ชื่อหมวดเอง
  (เช่น `ของไม่มีป้าย`) ระบบจะเก็บเป็นยอดนอกทะเบียนไว้เทียบต่างหาก
- ลบยอดที่นับผิดได้จากรายการด้านล่างในหน้าต่างเดียวกัน
- ดูภาพรวมทุกหมวดได้ที่ **Dashboard → เทียบยอดนับจำนวน** และมีชีท **"นับจำนวนตามหมวด"** ในไฟล์ Excel

## ประวัติการบันทึก (ตามหา/แก้รายการที่บันทึกผิด)

หน้ารายการ → ปุ่ม **ประวัติการบันทึก** — รวมทุกการบันทึกของรอบนี้เรียงตามเวลา

- กรองตาม **ผู้บันทึก** · **ผล** (พบ/ไม่พบ/ย้ายออก) · **ช่วงเวลา** (วันนี้ / 24 ชม. / 7 วัน)
- เรียง **บันทึกล่าสุดก่อน** หรือ **เก่าสุดก่อน** · ค้นหาด้วย RT code หรือตำแหน่งที่ตรวจ
- ปุ่ม **ดินสอ** = เปิดรายการนั้นเพื่อบันทึกผลใหม่ทับ (ระบบเก็บทุกครั้งไว้ ผลล่าสุดคือผลที่ใช้จริง)
- ปุ่ม **ถังขยะ** = ลบรายการที่บันทึกผิดออกจากประวัติ
  **ผู้ตรวจลบได้เฉพาะรายการที่ตัวเองบันทึก** ส่วนผู้ดูแลลบได้ทุกรายการ

---

## พื้นที่จัดเก็บ (จำกัดขอบเขตการตรวจ)

ใช้ตอนตรวจคลังกลางหรือพื้นที่ใหญ่ที่ต้องแบ่งกันตรวจทีละโซน

**พื้นที่มาจากไหน** — ระบบอ่านจากคอลัมน์ `Location` ในไฟล์ทะเบียน หรือ `Port ED - Text` ของไฟล์ SAP
(รองรับชื่อหัวคอลัมน์: Location / พื้นที่ / พื้นที่จัดเก็บ / สถานที่เก็บ / จุดเก็บ / Port ED - Text)
และอ่าน **รหัสพื้นที่** จากคอลัมน์ `Port ED` (หรือ Location Code / รหัสพื้นที่) มาแสดงนำหน้าชื่อโซนให้ทุกที่
เช่น **`Z006 · โกดัง 1`** — ทั้งในตัวกรอง, คอลัมน์พื้นที่จัดเก็บ, แผงเลือกพื้นที่, กราฟ Dashboard และแผนที่
· ค้นหาด้วยรหัสโซนได้ (พิมพ์ `Z007` เจอ `โกดัง 2`)

> รหัสเป็นแค่ป้ายกำกับบนจอ — ค่าที่บันทึกลงผลตรวจและทะเบียนยังเป็น**ชื่อโซนล้วน**เหมือนเดิม
> ไฟล์ Excel ที่ export ออกไปจึงยังตรงกับ SAP ทุกช่อง
> ถ้าไม่เห็นรหัสขึ้นมา แปลว่าไฟล์ทะเบียนที่อัปโหลดไว้ยังไม่มีคอลัมน์ `Port ED` — เพิ่มคอลัมน์แล้วสร้างรอบใหม่ได้เลย

- **ตัวกรอง "พื้นที่"** ในหน้ารายการ — เลือกโซนแล้วเห็นเฉพาะของในโซนนั้น
  และตัวนับเปลี่ยนเป็น "ตรวจแล้ว x / y" **ของโซนนั้น**
- รายการที่ไฟล์ยังไม่ได้ระบุพื้นที่จะรวมอยู่ใต้ **(ไม่ระบุพื้นที่)** เลือกกรองดูได้
- **ช่องเดียวจบ**: ในฟอร์มบันทึกผลมีช่อง "พื้นที่ / ตำแหน่งที่ตรวจ" ช่องเดียว พิมพ์แก้ได้ตลอด
  · ทะเบียนระบุพื้นที่ไว้แล้ว → ขึ้นค่านั้นให้ แก้ได้ถ้าไม่ตรงของจริง
  · ทะเบียนยังไม่ระบุ → ขึ้น**พื้นที่ล่าสุดที่คุณเพิ่งบันทึกไว้** (ของแต่ละคนแยกกัน) เดินตรวจทีละโซนจึงกดรัวได้เลย
  · บันทึกแล้วระบบเติม/อัปเดตพื้นที่ลงทะเบียนให้อัตโนมัติ
- **ดูพื้นที่ที่มีอยู่ทั้งหมด**: กดปุ่ม 📍 ที่อยู่ข้างช่องพื้นที่ (มีทุกจุดที่กรอกพื้นที่ได้)
  จะเปิดรายการพื้นที่ทั้งหมดพร้อมบอกว่าแต่ละพื้นที่มีของในทะเบียนกี่ชิ้น · ค้นหาได้ · พิมพ์ชื่อใหม่ได้
  · มีปุ่ม "ไม่ระบุพื้นที่" ไว้ล้างค่า
  > ที่เห็นไม่ครบตอนกดลูกศรในช่อง เพราะ dropdown ของเบราว์เซอร์กรองตามข้อความที่อยู่ในช่องอยู่แล้ว
  > ปุ่ม 📍 จึงเป็นทางที่เห็นครบเสมอ
- **กำหนดทีละหลายรายการ**: ติ๊กเลือกในตาราง → ปุ่ม **กำหนดพื้นที่** ในแถบด้านล่าง
- Dashboard มีกราฟ **ตามพื้นที่จัดเก็บ** และไฟล์ Excel มีคอลัมน์ **พื้นที่จัดเก็บ** ต่อท้ายฟอร์ม

> การแก้พื้นที่เป็นการแก้ "ทะเบียน" จึงต้องออนไลน์ — ส่วนการบันทึกผลตรวจยังทำออฟไลน์ได้ตามปกติ

## ดูรูปที่ถ่ายไว้

รายการไหนที่แนบรูปตอนตรวจ จะมี **ปุ่มดูรูป** ให้กดได้จาก 4 ที่:

| ที่ไหน | ปุ่ม |
|---|---|
| **แผนที่** (Dashboard) | ปุ่มเขียว **ดูรูป (n)** ในป๊อปอัปของหมุด |
| **ประวัติการบันทึก** | ปุ่มกล้อง 📷 มีเลขบอกจำนวนรูปมุมขวาบน |
| **มุมมองการ์ด** | ป้าย **ดูรูป (n)** ใต้ชื่อทรัพย์สิน |
| **หน้ารายละเอียดทรัพย์สิน** | ปุ่ม **รูป 1 / รูป 2 …** ในบรรทัดประวัติการตรวจ |

กดแล้วรูปเปิดในแอปเลย ไม่เด้งออกไปแท็บอื่น — เลื่อนดูรูปถัดไปด้วยปุ่ม ‹ › และกด
**เปิดรูปเต็ม / บันทึกรูป** เพื่อเปิดไฟล์เต็มหรือเซฟลงเครื่อง

> รูปที่ถ่ายตอนออฟไลน์ (ยังไม่ได้ส่ง) ก็เปิดดูได้ทันทีจากในเครื่อง

---

## แผนที่จุดที่บันทึก (ใน Dashboard)

Dashboard มีการ์ด **แผนที่จุดที่บันทึก** แสดงหมุดของทุกการบันทึกที่มีพิกัด GPS

- **สีหมุดบอกผล**: เขียว = พบ · แดง = ไม่พบ · น้ำเงิน = ย้ายออก
- **แตะหมุด** เห็นรายละเอียด: RT code · ชื่อทรัพย์สิน · ผล · ผู้บันทึก · เวลา · ตำแหน่งที่ตรวจ ·
  พื้นที่ในทะเบียน · หมายเหตุ · ความแม่นยำ GPS · จำนวนรูป
- **กรองได้**: ผู้บันทึก / ช่วงเวลา (วันนี้ · 24 ชม. · 7 วัน) / พื้นที่จัดเก็บ
- **สลับรูปแบบแผนที่**ได้ที่มุมขวาบนของแผนที่: **แผนที่ถนน · ภาพดาวเทียม · ดาวเทียม + ชื่อสถานที่**
  (ระบบจำแบบที่เลือกล่าสุดไว้ให้)
- ในป๊อปอัปมีปุ่ม **เปิดใน Google Maps ↗** — กดแล้วเด้งไปแอป Google Maps ที่จุดนั้นเลย
  ใช้นำทางหรือดู Street View ต่อได้
- แผนที่ใช้ OpenStreetMap — **ต้องต่ออินเทอร์เน็ตตอนเปิด Dashboard** (ถ้าออฟไลน์จะขึ้นข้อความแจ้ง
  ส่วนหน้าอื่นยังใช้ได้ตามปกติ)

**พิกัดมาจากไหน** — ระบบขอตำแหน่งจากเครื่องตอนเปิดรอบตรวจ แล้วแนบพิกัดล่าสุดให้**ทุกวิธีบันทึก**
(สแกน · ฟอร์มเต็ม · ติ๊ก Yes/No · เลือกหลายรายการ · โหมดตรวจต่อเนื่อง) โดยไม่หน่วงการบันทึก
ถ้าไม่อนุญาตให้ใช้ตำแหน่ง ระบบยังบันทึกได้ตามปกติ แค่ไม่มีหมุดบนแผนที่

> GPS ในอาคาร/โกดังคลาดเคลื่อนราว 10–50 เมตร ใช้ดูว่า "ตรวจแถวไหน อาคารไหน" ได้
> แต่ไม่ละเอียดถึงระดับชั้นวาง — ถ้าต้องการละเอียดให้ใช้ช่อง "พื้นที่ / ตำแหน่งที่ตรวจ" ควบคู่กัน

---

## รายการค้างส่ง (แถบ "รอส่ง" ที่มุมบนขวา)

แตะแถบ **รอส่ง** เพื่อดูว่ามีอะไรค้างและ**ค้างเพราะอะไร**

- ถ้าเหตุผลขึ้นว่า "ยังไม่ได้ติดตั้ง..." ให้ไปรันไฟล์ SQL ที่ระบุใน Supabase ก่อน แล้วกด **ลองส่งอีกครั้ง**
- **ทิ้งรายการนี้ / ทิ้งทั้งหมด** = เอาออกจากคิวถาวร (ใช้เมื่อข้อมูลนั้นไม่ต้องการแล้ว)
- รายการที่ส่งไม่ผ่านตัวเดียว **จะไม่บล็อกรายการอื่นอีกต่อไป** ระบบข้ามไปส่งตัวถัดไปให้เอง

**ส่งไม่ผ่านจะไม่เงียบอีกต่อไป** — ถ้าเซิร์ฟเวอร์ปฏิเสธ (บัญชีถูกปิดสิทธิ์ เซสชันหมดอายุ ระบบยังติดตั้งไม่ครบ)
จะเด้งข้อความแดงบอกสาเหตุทันทีตั้งแต่รายการแรก และแถบ "รอส่ง" **เปลี่ยนเป็นสีแดง** จนกว่าจะส่งได้
(สีส้ม = แค่รอส่งตามปกติ เช่น กำลังออฟไลน์)

> เน็ตหลุดตอนกดส่งแล้วผลตรวจ "หายจากจอ" — แก้แล้วตั้งแต่ v2.8.0 ระบบจะดึงแถวที่บันทึกไว้แล้วกลับมาแสดงให้เอง
> ไม่ต้องเดินไปบันทึกซ้ำ

## เลือกคอลัมน์ที่จะแสดงในตาราง

หน้ารายการ → ปุ่ม **คอลัมน์** — ติ๊กเปิด/ปิดได้ทุกคอลัมน์ (Inventory Number, Description และช่อง Yes/No
เป็นแกนหลักของฟอร์มจึงปิดไม่ได้)

- **แสดงทั้งหมด** / **เหลือเฉพาะหลัก** / **อัตโนมัติ** (ค่าเริ่มต้น — ซ่อนคอลัมน์รองเองเมื่อจอแคบ)
- เมื่อเลือกเอง คอลัมน์ที่ติ๊กไว้จะแสดง**ทุกขนาดจอ** รวมถึงบนมือถือ
- จำค่าไว้ให้แยกกันระหว่าง **Fixed Assets** กับ **ของเช่า** และจำข้ามการเปิดแอปครั้งถัดไป

## ผลการตรวจ 3 แบบ

| ปุ่ม | ใช้เมื่อ |
|---|---|
| ✅ **พบ** | เจอของในพื้นที่ (= ติ๊ก Yes ในฟอร์ม) |
| ❌ **ไม่พบ** | หาไม่เจอในพื้นที่ (= ติ๊ก No ในฟอร์ม) |
| 🚚 **ย้ายออก** | ถูกส่งไปไซต์อื่นแล้ว — กรอกเพิ่ม: **ส่งไป SITE / เลขที่ใบส่ง / วันที่ส่ง** |

ถ้าของชำรุดหรือมีรายละเอียดอื่น ให้เขียนไว้ในช่อง **หมายเหตุ** และถ่ายรูปประกอบ

ทุกแบบกรอก **หมายเหตุ** ได้ และแนบรูปได้

## ข้อมูลที่ระบบบันทึกให้อัตโนมัติ

ทุกครั้งที่กดบันทึก ระบบจะแนบสิ่งเหล่านี้ให้เองโดยไม่ต้องทำอะไร:

- **ชื่อผู้ตรวจ** (จากบัญชีที่ login)
- **วันเวลา** ตามเวลาไทย แสดงเป็น พ.ศ.
- **วิธีตรวจ** — ป้าย `SCAN` (สแกน QR) หรือ `MANUAL` (เลือกเอง/พิมพ์เอง)
- **พิกัด GPS** (ถ้าอนุญาตและจับสัญญาณได้ — ไม่ได้ก็บันทึกได้ตามปกติ ไม่บล็อก)

**ตำแหน่งที่ตรวจ** (อาคาร/ชั้น/ห้อง/โซน) พิมพ์ครั้งเดียว ระบบจะจำไว้เป็นค่าตั้งต้นของรายการถัดไป
เพราะปกติตรวจไล่ทีละห้อง — เปลี่ยนเมื่อย้ายห้องเท่านั้น

## รูปถ่าย

- กด **📷 ถ่ายรูป** เพื่อถ่ายสด หรือ **🖼 จากแกลเลอรี** เพื่อเลือกรูปที่ถ่ายไว้
- แนบได้สูงสุด 5 รูปต่อการตรวจ 1 ครั้ง
- ระบบย่อรูปให้อัตโนมัติก่อนส่ง จึงส่งได้เร็วแม้เน็ตหน้างานอ่อน

## เน็ตหลุด ข้อมูลไม่หาย

ระบบบันทึกลงเครื่องคุณก่อนเสมอ แล้วค่อยส่งขึ้นเซิร์ฟเวอร์

- ขณะไม่มีเน็ต: **บันทึกได้ตามปกติ** จะเห็นป้ายส้ม **⏳ รอส่ง x** บนหัวจอ และแถวนั้นมีคำว่า "รอส่ง"
- พอเน็ตกลับมา: ระบบส่งให้เองอัตโนมัติ ป้ายจะหายไป (แตะที่ป้ายเพื่อสั่งส่งทันทีก็ได้)
- **อย่าล้างข้อมูลเบราว์เซอร์ขณะที่ยังมีป้าย "รอส่ง" ค้างอยู่** ข้อมูลที่ยังไม่ส่งจะหาย

## RT code เดียวกันติดอยู่หลายชิ้น

หน้างานจริงมี RT code เดียวกันถูกติดไว้กับของ 2–3 ชิ้นคนละที่ ระบบรองรับกรณีนี้แล้ว

เมื่อสแกนหรือบันทึก RT code ที่บันทึกไปแล้ว จะมีกล่องขึ้นมาให้เลือก:

| ปุ่ม | ใช้เมื่อ | ผล |
|---|---|---|
| **พบอีกชิ้น — นับเป็นชิ้นที่ N** | เป็นของคนละชิ้นที่ใช้ RT code ซ้ำกัน | จำนวนชิ้นเพิ่มขึ้น 1 |
| **แก้ไขผลเดิม** | ของชิ้นเดิม บันทึกผิดหรือเปลี่ยนผล | จำนวนไม่เพิ่ม ทับผลเดิมของชิ้นนั้น |
| ยกเลิก | กดผิด | ไม่บันทึกอะไร |

กล่องนี้แสดงด้วยว่าตอนนี้บันทึกไว้แล้วกี่ชิ้น และแต่ละชิ้นผลเป็นอะไร

ในตารางจะเห็นป้าย **× 2** ต่อท้ายสถานะ และในไฟล์ Excel มีคอลัมน์ **จำนวนที่บันทึก (ชิ้น)**
พร้อมตารางสรุป "RT code ที่ใช้ซ้ำหลายชิ้น" ในชีทสรุปผล

## ตรวจพร้อมกันหลายคน

- ทุกคนเห็นผลของกันและกันภายในไม่กี่วินาที ไม่ต้องกดรีเฟรช (กดปุ่ม ↻ มุมขวาบนได้ถ้าอยากบังคับ)
  — รวมถึง**ยอดนับจำนวน**และ**รายการที่ถูกลบ**ด้วย
- ถ้าจะบันทึกรายการที่คนอื่นตรวจไปแล้ว ระบบเตือนก่อนเสมอว่าใครตรวจเมื่อไหร่
- การบันทึกซ้ำจะ**เพิ่มเป็นรายการใหม่ต่อท้าย ไม่ทับของเดิม** — ประวัติทุกครั้งดูย้อนหลังได้ในหน้ารายละเอียด
  (สถานะที่แสดงในรายการ = ผลการตรวจครั้งล่าสุด)

### กดบันทึกรหัสเดียวกันพร้อมกันเป๊ะๆ

กรณีนี้ต่างฝ่ายต่างยังไม่เห็นของกัน จึงไม่มีกล่องให้เลือกก่อนบันทึก ระบบจะ**เตือนย้อนหลังทันที**ที่ผลของอีกฝ่ายมาถึง

| สถานการณ์ | ข้อความที่ขึ้น |
|---|---|
| ผลตรงกัน | `สมหญิง (B) บันทึก RT-… ซ้ำกับของคุณ (พบ)` |
| ผลไม่ตรงกัน | `สมหญิง (B) บันทึก RT-… เป็น "ไม่พบ" ทับผลของคุณ ("พบ") — แตะเพื่อตรวจสอบ` |

แตะที่ข้อความเตือนเพื่อเปิดรายการนั้นดูประวัติทั้งหมดและบันทึกผลที่ถูกต้องทับได้เลย
ข้อมูลไม่หาย — ทุกครั้งที่บันทึกถูกเก็บไว้ครบ และทุกเครื่องสรุปสถานะตรงกันเสมอ

### นับจำนวนพร้อมกัน

ยอดนับเป็นการ**บวกสะสม** ถ้ามีคนอื่นเพิ่งนับหมวดเดียวกันในพื้นที่เดียวกันภายใน 10 นาที
ระบบจะถามยืนยันก่อนบันทึก (บอกชื่อคนนับ จำนวน และเวลา) เพื่อกันการนับกองเดียวกันซ้ำสองรอบ

## ตัวกรองและการเรียง

- **หมวด** — เลือกจากรหัสหมวดที่มีจริง เช่น `RT-TAXX` (โต๊ะ) `RT-MDBX` (ตู้โหลด)
- **ผู้รับผิดชอบ** — เฉพาะแท็บ Fixed (มีตัวเลือก "(ไม่ระบุ)" สำหรับรายการที่ยังไม่ระบุคน)
- **สถานะ** — ทั้งหมด / ยังไม่ตรวจ / พบ / ชำรุด / ไม่พบ / ย้ายออก
- **เรียงตาม** — รหัสทรัพย์สิน / ตรวจล่าสุดก่อน / ชื่อทรัพย์สิน

ใช้หลายตัวกรองพร้อมกันได้ และตัวนับ "ตรวจแล้ว x / y" จะเปลี่ยนตามเงื่อนไขที่กรองอยู่

## สรุปผลและ Excel

แท็บ **📊 สรุปผล** แสดง:

- **การ์ดตัวเลขหลัก 4 ใบ** — ทรัพย์สินทั้งหมด · ตรวจแล้ว (%) · ไม่พบ · ย้ายออก/พบเพิ่ม
- **วงแหวนสัดส่วนผลการตรวจ** พร้อมตัวเลขและ % แต่ละสถานะ
- **กราฟจำนวนที่ตรวจต่อวัน** (14 วันล่าสุด)
- ความคืบหน้าแยก Fixed / ของเช่า · แยกตามหมวดรหัส · แยกตามผู้รับผิดชอบ · ผลงานผู้ตรวจ
- **ตารางรายการตรวจล่าสุด** 8 รายการ
- รายการ **ยังไม่ตรวจ / ไม่พบ / ย้ายออก / นอกทะเบียน** (แตะที่รายการเพื่อเปิดบันทึกได้ทันที)

ปุ่ม **⬇ ดาวน์โหลด Excel** ได้ไฟล์ 5 ชีทของรอบนั้น:

1. **สรุปผล** — ข้อมูลรอบ + ตารางสรุป (ตามทะเบียน/ตรวจแล้ว/พบ/ไม่พบ/ย้ายออก/ยังไม่ตรวจ
   แยก Fixed–ของเช่า–รวม) + จำนวน**ที่พบเพิ่มนอกทะเบียน**พร้อมรายชื่อ
2. **ทรัพย์สิน Fixed Assets** — หน้าตาเหมือนฟอร์มรายงานต้นฉบับทุกประการ (หัวรายงาน 4 บรรทัด,
   หัวตาราง 3 ชั้นแบบผสานช่อง) ช่อง **Yes / No แยกกัน 2 คอลัมน์** ติ๊ก ✓ ให้ตามผลตรวจ
   พร้อมคอลัมน์ย้ายออก · **หมายเหตุจะว่างถ้าไม่ได้กรอกอะไร** · ต่อท้ายมีคอลัมน์เสริม
   **จำนวนที่บันทึก (ชิ้น) · ผู้บันทึก · เวลาที่บันทึก · ตำแหน่งที่ตรวจ · วิธี** — พิมพ์ออกมาเซ็นได้เลย
3. **ทรัพย์สินของเช่า** — ฟอร์มเดียวกันของชีทของเช่า
4. **รูปถ่ายยืนยัน** — **รูปจริงฝังอยู่ในไฟล์** (โครงเดียวกับ MCR) เปิดดูได้ทันทีไม่ต้องต่อเน็ต
   แต่ละแถวมี RT code · ชื่อทรัพย์สิน · ผลตรวจ · ผู้บันทึก · เวลา · ตำแหน่ง · รูป
5. **ประวัติการตรวจทั้งหมด** — ทุกครั้งที่บันทึก เรียงตามเวลา มีคอลัมน์ "ชิ้นที่" (ไว้ตรวจย้อนหลัง)

> ไฟล์ที่มีรูปเยอะจะใช้เวลาสร้างนานขึ้น (ระบบขึ้นตัวนับ "กำลังใส่รูปภาพ x / y" ให้เห็น)

## เปลี่ยนธีมหน้าเว็บ

แท็บ **⚙ จัดการ** → หัวข้อ "ธีมหน้าเว็บ" เลือกได้ 4 แบบ: **Porcelain** (ขาว-น้ำเงิน, ค่าเริ่มต้น) ·
**Graphite** (พื้นเข้ม-ทอง) · **Ink & Serif** (ครีม-แดงเลือดหมู) · **Organic** (ครีมทราย-ดินเผา)
ระบบจำค่าไว้ในเครื่องนั้น ๆ ใครชอบแบบไหนตั้งของตัวเองได้
