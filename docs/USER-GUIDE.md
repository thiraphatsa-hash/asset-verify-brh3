# คู่มือใช้งานสำหรับทีมตรวจทรัพย์สิน

เปิดเว็บด้วยมือถือหรือแท็บเล็ต ไม่ต้องติดตั้งแอป — แนะนำให้ "เพิ่มไปยังหน้าจอโฮม" จะเปิดง่ายเหมือนแอปทั่วไป

---

## เริ่มต้นครั้งแรก

1. เปิดลิงก์ที่หัวหน้าทีมส่งให้ → กด **สมัครสมาชิก** → กรอกอีเมลและรหัสผ่าน (อย่างน้อย 6 ตัว)
2. รอหัวหน้าทีมอนุมัติ (หน้าจอจะพาเข้าระบบเองอัตโนมัติ ไม่ต้องกดรีเฟรช)
3. ครั้งต่อไปเครื่องจะจำการเข้าระบบไว้ ไม่ต้อง login ใหม่ทุกวัน

**ชื่อผู้ตรวจ** จะถูกบันทึกอัตโนมัติจากบัญชีของคุณในทุกครั้งที่บันทึก ไม่ต้องกรอกเอง

---

## หน้าจอหลัก

แถบล่างสุดมี 4–5 ปุ่ม:

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| 🏢 Fixed | ทรัพย์สินของบริษัท 270 รายการ |
| 🚚 ของเช่า | ทรัพย์สินเช่า 36 รายการ (ตู้คอนเทนเนอร์ ตู้ไฟ แอร์ ห้องน้ำ) |
| ▣ ปุ่มส้มกลางจอ | **สแกน QR** |
| 📊 สรุปผล | ความคืบหน้า + ดาวน์โหลด Excel |
| ⚙ จัดการ | เฉพาะหัวหน้าทีม |

ทรัพย์สิน 2 ประเภทแยกกันคนละแท็บชัดเจน มีตัวนับ "ตรวจแล้ว x / y" ของตัวเอง
(ถ้าสแกนเจอของอีกประเภท ระบบก็เปิดให้บันทึกได้เลย ไม่ต้องสลับแท็บก่อน)

**สีขอบซ้ายของแต่ละแถว** บอกสถานะทันที: เขียว = พบปกติ · ส้ม = ชำรุด · แดง = ไม่พบ ·
น้ำเงิน = ย้ายออก · เทา = ยังไม่ตรวจ

---

## วิธีที่ 1: ตรวจด้วยการสแกน QR (เร็วที่สุด)

1. กดปุ่มส้มกลางจอ → อนุญาตให้ใช้กล้อง (ถามครั้งแรกครั้งเดียว)
2. เล็ง QR ที่ติดบนทรัพย์สินให้อยู่ในกรอบส้ม
3. เครื่องจะ**ร้องปี๊บ + สั่น** แล้วเด้งข้อมูลทรัพย์สินขึ้นมาให้ตรวจสอบ
4. เลือกผลการตรวจ → กด **บันทึกผลตรวจ**
5. กล้องกลับมาพร้อมสแกนตัวถัดไปทันที

ถ้าสแกนแล้ว**ไม่พบรหัสในทะเบียน** ระบบจะแจ้งพร้อมให้เลือก "สแกนต่อ" หรือ
"บันทึกนอกทะเบียน" (สำหรับของที่มีอยู่จริงหน้างานแต่ไม่มีในไฟล์ทะเบียน)

---

## วิธีที่ 2: ตรวจด้วยการเลือกจากรายการ

1. ค้นหาด้วยช่องบนสุด (พิมพ์ได้ทั้งรหัส ชื่อ Serial ชื่อผู้รับผิดชอบ — พิมพ์หลายคำได้ ระบบหาที่ตรงครบทุกคำ)
2. แตะแถวที่ต้องการ → เลือกผลการตรวจ → บันทึก

---

## วิธีที่ 3: โหมดตรวจต่อเนื่อง (ของหมวดเดียวกันจำนวนมาก)

เหมาะกับตรวจของชนิดเดียวกันเรียงกันเยอะๆ เช่น ตู้โหลด `RT-MDBX` หลายสิบตัว

1. กดปุ่ม **⚡ โหมดตรวจต่อเนื่อง**
2. เลือกหมวด เช่น `RT-MDBX` → ระบบจะ**ค้าง prefix ไว้ให้**
3. กรอกเฉพาะ**ส่วนท้าย**ของรหัส แล้วกดบันทึก เช่น
   - พิมพ์ `07-766` → ได้ `RT-MDBX-07-0766`
   - พิมพ์ `260001` (ไม่ต้องมีขีดก็ได้) → ได้ `RT-MDBX-26-0001`
4. ช่องกรอกจะเคลียร์ให้เองพร้อมรับตัวถัดไป **prefix ยังอยู่** และเคอร์เซอร์กลับมาที่ช่องเดิมอัตโนมัติ
5. มีตัวนับสะสม "ตรวจแล้ว x / y รายการในหมวดนี้" ให้เห็นตลอด

ถ้ากรอกรหัสที่มีคนตรวจไปแล้ว ระบบจะ**เตือนทันทีว่าใครตรวจ เมื่อไหร่ ผลเป็นอะไร** แล้วให้เลือกว่าจะบันทึกซ้ำหรือไม่

---

## ผลการตรวจ 4 แบบ

| ปุ่ม | ใช้เมื่อ |
|---|---|
| ✅ **พบ · ปกติ** | เจอของ สภาพใช้งานได้ |
| 🛠 **พบ · ชำรุด** | เจอของ แต่ชำรุด/เสียหาย (ควรถ่ายรูปประกอบ) |
| ❌ **ไม่พบ** | หาไม่เจอในพื้นที่ |
| 🚚 **ย้ายออก** | ถูกส่งไปไซต์อื่นแล้ว — กรอกเพิ่ม: **ส่งไป SITE / เลขที่ใบส่ง / วันที่ส่ง** |

ทุกแบบกรอก **หมายเหตุ** ได้ และแนบรูปได้

---

## ข้อมูลที่ระบบบันทึกให้อัตโนมัติ

ทุกครั้งที่กดบันทึก ระบบจะแนบสิ่งเหล่านี้ให้เองโดยไม่ต้องทำอะไร:

- **ชื่อผู้ตรวจ** (จากบัญชีที่ login)
- **วันเวลา** ตามเวลาไทย แสดงเป็น พ.ศ.
- **วิธีตรวจ** — ป้าย `SCAN` (สแกน QR) หรือ `MANUAL` (เลือกเอง/พิมพ์เอง)
- **พิกัด GPS** (ถ้าอนุญาตและจับสัญญาณได้ — ไม่ได้ก็บันทึกได้ตามปกติ ไม่บล็อก)

**ตำแหน่งที่ตรวจ** (อาคาร/ชั้น/ห้อง/โซน) พิมพ์ครั้งเดียว ระบบจะจำไว้เป็นค่าตั้งต้นของรายการถัดไป
เพราะปกติตรวจไล่ทีละห้อง — เปลี่ยนเมื่อย้ายห้องเท่านั้น

---

## รูปถ่าย

- กด **📷 ถ่ายรูป** เพื่อถ่ายสด หรือ **🖼 จากแกลเลอรี** เพื่อเลือกรูปที่ถ่ายไว้
- แนบได้สูงสุด 5 รูปต่อการตรวจ 1 ครั้ง
- ระบบย่อรูปให้อัตโนมัติก่อนส่ง จึงส่งได้เร็วแม้เน็ตหน้างานอ่อน

---

## เน็ตหลุด ข้อมูลไม่หาย

ระบบบันทึกลงเครื่องคุณก่อนเสมอ แล้วค่อยส่งขึ้นเซิร์ฟเวอร์

- ขณะไม่มีเน็ต: **บันทึกได้ตามปกติ** จะเห็นป้ายส้ม **⏳ รอส่ง x** บนหัวจอ และแถวนั้นมีคำว่า "รอส่ง"
- พอเน็ตกลับมา: ระบบส่งให้เองอัตโนมัติ ป้ายจะหายไป (แตะที่ป้ายเพื่อสั่งส่งทันทีก็ได้)
- **อย่าล้างข้อมูลเบราว์เซอร์ขณะที่ยังมีป้าย "รอส่ง" ค้างอยู่** ข้อมูลที่ยังไม่ส่งจะหาย

---

## ตรวจพร้อมกันหลายคน

- ทุกคนเห็นผลของกันและกันภายในไม่กี่วินาที ไม่ต้องกดรีเฟรช (กดปุ่ม ↻ มุมขวาบนได้ถ้าอยากบังคับ)
- ถ้าจะบันทึกรายการที่คนอื่นตรวจไปแล้ว ระบบเตือนก่อนเสมอว่าใครตรวจเมื่อไหร่
- การบันทึกซ้ำจะ**เพิ่มเป็นรายการใหม่ต่อท้าย ไม่ทับของเดิม** — ประวัติทุกครั้งดูย้อนหลังได้ในหน้ารายละเอียด
  (สถานะที่แสดงในรายการ = ผลการตรวจครั้งล่าสุด)

---

## ตัวกรองและการเรียง

- **หมวด** — เลือกจากรหัสหมวดที่มีจริง เช่น `RT-TAXX` (โต๊ะ) `RT-MDBX` (ตู้โหลด)
- **ผู้รับผิดชอบ** — เฉพาะแท็บ Fixed (มีตัวเลือก "(ไม่ระบุ)" สำหรับรายการที่ยังไม่ระบุคน)
- **สถานะ** — ทั้งหมด / ยังไม่ตรวจ / พบ / ชำรุด / ไม่พบ / ย้ายออก
- **เรียงตาม** — รหัสทรัพย์สิน / ตรวจล่าสุดก่อน / ชื่อทรัพย์สิน

ใช้หลายตัวกรองพร้อมกันได้ และตัวนับ "ตรวจแล้ว x / y" จะเปลี่ยนตามเงื่อนไขที่กรองอยู่

---

## สรุปผลและ Excel

แท็บ **📊 สรุปผล** แสดง:

- ความคืบหน้าแยก Fixed / ของเช่า พร้อมจำนวนแต่ละสถานะ
- ความคืบหน้าแยกตามหมวดรหัส และตามผู้รับผิดชอบ
- จำนวนครั้งที่แต่ละคนบันทึก
- รายการ **ยังไม่ตรวจ / ไม่พบ / ย้ายออก / นอกทะเบียน** (แตะที่รายการเพื่อเปิดบันทึกได้ทันที)

ปุ่ม **⬇ ดาวน์โหลด Excel** ได้ไฟล์ 3 ชีท: `Fixed Assets`, `ของเช่า` (ทะเบียนเต็มพร้อมผลตรวจล่าสุด
ต่อท้ายทุกคอลัมน์) และ `ประวัติการตรวจทั้งหมด` (ทุกครั้งที่บันทึก เรียงตามเวลา)
