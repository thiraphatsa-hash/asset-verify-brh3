รายการค้างส่ง

รายการที่ส่งไม่ผ่านจะขึ้นสาเหตุไว้ให้ · ถ้าสาเหตุคือ "ยังไม่ได้ติดตั้ง..." ให้รันไฟล์ SQL ที่ระบุใน Supabase ก่อนแล้วกดลองส่งอีกครั้ง

นับจำนวนตามหมวด

ใช้ตอนเจอของหน้างานแต่ไม่ทราบ RT code เช่น เก้าอี้กองรวมกัน — เลือกหมวดแล้วกรอกจำนวนที่นับได้ ระบบเก็บแยกจากผลตรวจรายชิ้น ไม่กระทบสถานะของรหัสใดๆ และรวมยอดสะสมให้เองถ้านับหลายจุด

บันทึกซ้ำ

RT code นี้ถูกบันทึกไปแล้วในรอบนี้

หน้างานจริงมี RT code เดียวกันติดอยู่กับของ 2–3 ชิ้นคนละที่ — เลือกให้ตรงกับสถานการณ์ ระบบจะนับจำนวนชิ้นและออกรายงานให้ถูกต้อง

มีคำขอใช้งานใหม่

อนุมัติแล้วผู้ใช้จะเข้าระบบได้ทันทีในบทบาท counter (บันทึกผลตรวจได้) — ปรับบทบาทหรือแก้ชื่อที่แสดงภายหลังได้ที่หน้าจัดการ
